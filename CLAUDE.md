## MEMORY

A staging area, not a permanent reference — each item below gets read and eventually either deleted (resolved, decided against, gone stale) or folded into the repo's own documentation once settled enough to become a standing convention. Not meant to just accumulate.

Flat root structure (skill folders only, no nested categories) is a deliberate ceiling, not a limitation being worked around. If a future need seems to require deeper hierarchy, the right move is a new, separate repo — never restructuring this one.

Skill count: 9 as of 2026-11-06, all doing real work, no toy/demo skills. Soft ceiling at 12, stated 2026-11-01 — not a target to approach, a cap to flag before crossing. A genuinely-earned skill past that point is a direct call, not a default assumption.

Release is deliberately held open as of 2026-11-04, even though the repo has felt ready more than once — intentional, not indecision. Don't read "this feels done" as a cue to suggest shipping/announcing/releasing.
